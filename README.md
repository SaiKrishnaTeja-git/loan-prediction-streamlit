# AI-Powered Loan Prediction & Financial Planning

An end-to-end **Machine Learning + AI application** that predicts loan approval and provides personalized financial planning recommendations through an interactive **Streamlit** application.

## Problem Statement

Traditional loan prediction models primarily answer:

> **"Will the loan be approved?"**

This project goes beyond prediction by combining **ML-based loan eligibility assessment with AI-powered personalization**, helping users understand their financial profile and explore relevant borrowing and repayment considerations.

## Key Features

* **Loan Prediction** — ML-based loan approval prediction.
* **Applicant Analysis** — Evaluates financial, demographic, and credit-related factors.
* **AI Personalization** — Generates profile-based recommendations.
* **Financial Planning** — Provides personalized borrowing and repayment insights.
* **Interactive App** — User-friendly Streamlit interface.
* **Deployment Ready** — Designed for Streamlit Community Cloud.

## Data & Features

The model uses historical loan application data including:

**Applicant:** Gender, Married, Dependents, Education
**Financial:** Applicant Income, Coapplicant Income
**Loan:** Loan Amount, Loan Term
**Credit:** Credit History
**Property:** Property Area
**Target:** Loan Status

The data pipeline includes **data cleaning, missing-value treatment, categorical encoding, feature preparation, and model evaluation**.
